# Exported Google Stitch Assets — Job Application Tracker UI

This directory contains the unmodified assets exported directly via the Google Stitch MCP from Project `projects/5548734684114454711` (**"Job Application Tracker UI"**, Design System `assets/53884af2d33c4172a6c129c0419edce3` — *"Dibimbing LMS - Job Application Tracking"*).

## Directory Structure

- [`manifest.json`](manifest.json): Machine-readable index mapping Stitch Screen IDs and titles to their local HTML, PNG, and Markdown files.
- `screens/`: 25 high-resolution PNG screenshots exported from Stitch (`2560px` desktop renders for 20 active screens + 5 base/iterative variants).
- `html/`: 25 standalone HTML/Tailwind CSS source exports corresponding to each generated Stitch screen.
- `docs/`: 4 Markdown/text specification nodes authored inside the Stitch canvas (`DESIGN.md`, `JAT Technical Handoff & Specification`, `SCREEN-INVENTORY.md`, `DESIGN-TO-REQUIREMENTS.md`).

> **Note:** As required by [`AGENTS.md`](../../AGENTS.md), these exported files serve as the visual and structural reference for building clean, reusable React + TypeScript components. Never place a reference screenshot as a page background or edit the approved Stitch screens without explicit instruction.
