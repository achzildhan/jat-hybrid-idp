## 1. Overview & Architecture

The Job Application Tracking (JAT) feature suite comprises 28 designed screens across two distinct user roles:
- **Student Persona (Bootcamp Participant)**: Submits proof of external job applications, tracks multi-phase quota progression, views reviewer validation feedback, and retracts pending submissions.
- **Admin / Talent Support Specialist Persona**: Configures multi-phase cohort schedules, manages student participant rosters, audits individual progress, and processes pending submissions via Human-in-the-Loop (HITL) evidence validation.

## 3. Component Reusability & Shared Patterns

1. **Status Badge Matrix (Dual-Channel)**:
   - `Accepted / Approved / Target Achieved`: `bg-emerald-50 text-emerald-800 border-emerald-200` + checkmark icon.
   - `Waiting Confirmation / In Review`: `bg-amber-50 text-amber-800 border-amber-200` + clock icon.
   - `Declined / Rejected / Not Achieved`: `bg-rose-50 text-rose-800 border-rose-200` + alert-circle icon.
   - `Belum Dimulai / Upcoming`: `bg-slate-100 text-slate-600 border-slate-200` + circle-outline icon.
2. **Backdrop & Modal Elevation**:
   - All modal dialogs and slide-over drawers utilize `backdrop-blur-sm bg-slate-900/40`.
   - Modals use centered positioning (`fixed inset-0 flex items-center justify-center p-4 z-50`).
3. **Data Table Ergonomics**:
   - Header: Sticky `#F8FAFC`, uppercase 11px semi-bold labels with sorting chevrons (`↕`).
   - Pagination: Fixed footer with range summary (*"Menampilkan X dari Y Data"*), rows-per-page dropdown, and numbered page pills with `#0BB1CB` active indicator.
