# Design reference images

These cropped PNGs were extracted from the supplied reference PDFs `Desain UI JAT_Student Side.pdf` and `Desain UI JAT_Admin Side.pdf`. They are visual references for Stitch, not editable Figma frames and not production assets.

## Student
- `student/batch-list.png`: batch list view.
- `student/batch-detail.png`: expanded batch detail/progress view.
- `student/add-application.png`: Add Proof of Application form and field options.
- `student/application-status.png`: submission detail with Waiting Confirmation state.
- `student/application-approved-state.png`: submission detail with accepted/approved state.
- `student/status-filter-and-phase-progress.png`: validation status filter and phase progress example.
- `student/delete-confirmation.png`: delete-proof confirmation state.

## Admin
- `admin/batch-management.png`: batch list.
- `admin/batch-create.png`: batch setup with phase/date ranges/targets.
- `admin/batch-detail.png`: batch overview and participants.
- `admin/student-progress.png`: participant detail and progress.
- `admin/applied-jobs-filter.png`: filter in Applied Jobs.
- `admin/applied-jobs.png`: Applied Jobs table.

## Request/HITL
- `request/request-list.png`: Request list/table.
- `request/request-filter.png`: Request filtering.
