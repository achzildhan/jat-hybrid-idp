# Antigravity Prompt 03 — Implement one Epic at a time

Act as a Senior Full-Stack Engineer.

Implement only this approved Epic: [EPIC ID + TITLE].

Read its requirements in `docs/PRD.md`, business rules in `docs/Business-Rules.md`, relevant task rows in `docs/Product-Backlog.md`, and design in `DESIGN.md`/approved Stitch assets.

Before editing:
- identify relevant files and data flows;
- state acceptance criteria;
- identify dependencies and unknowns;
- propose a limited change plan.

Rules:
- follow the approved project stack and reusable components;
- do not rewrite unrelated files;
- do not invent endpoint/API/database details;
- if backend is not approved/available, implement through mock adapter only and mark the behavior as mocked;
- enforce input/business rules in trusted logic as well as user-friendly UI validation;
- do not treat LLM output as trusted data;
- write/update tests for the implemented behavior;
- run relevant tests and report the real output.

After implementation report: files changed, acceptance criteria fulfilled/unfulfilled, tests executed, issues/TBDs, and manual verification instructions. Do not start another Epic until reviewed.
