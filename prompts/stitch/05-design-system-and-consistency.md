# Stitch Prompt 05 — Consistency, design system, and DESIGN.md

Review all screens produced in this Stitch project as a single product, not as independent mockups.

Tasks:
1. Check consistency of navigation, page titles, typography, spacing, buttons, field labels, tables, pagination, dialogs, drawers, status chips and empty/error/loading states.
2. Compare each screen against the uploaded design references and the approved PRD.
3. Identify elements that diverge from the reference and either correct them or explain why an improvement is necessary.
4. Check accessibility: contrast, focus indicators, label clarity, text sizing, error feedback, keyboard behavior, and states that rely only on color.
5. Ensure responsive behavior on a standard desktop width and smaller viewport.
6. Ensure all clickable prototype paths lead to the expected screen/state.
7. Remove unsupported, redundant menus and fields.
8. Create/export a root-level `DESIGN.md` documenting actual design decisions made in the project: design principles, tokens, color roles and values, typography, spacing, components, interaction states, responsive guidance, and accessibility notes. Only include values that are actually selected in this project; distinguish tokens inferred from source references from new decisions.
9. If the platform supports a connected multi-screen prototype, verify the end-to-end Student and Admin paths.

Do not implement backend behavior. Report unresolved product questions separately rather than making up business rules.
