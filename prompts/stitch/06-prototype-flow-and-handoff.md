# Stitch Prompt 06 — Clickable prototype and handoff

Prepare the JAT Stitch design for implementation by a coding agent.

1. Ensure the prototype demonstrates these flows end to end:
   - Student: batch list → batch detail → add application → form/file validation → application status/detail.
   - Admin: batch list → create/edit batch → participant/progress → Applied Jobs.
   - Admin: Request queue → evidence review → confirm/reject → updated status.
2. Mark demo/mock results visibly where real backend/AI functionality is not connected.
3. Produce a screen inventory with each screen name and the UI states it supports.
4. Produce the approved `DESIGN.md` and ensure it is exportable/downloadable.
5. Export/hand off the design and frontend output to Google Antigravity if the current Stitch interface supports it. Do not treat exported code as production-ready by default; it must be reviewed, modularized, and tested.
6. If direct export is unavailable, provide images and code assets with clear file names and explain the manual export path.
7. Provide a final design review summary with completed flows, known gaps, and open decisions.

Do not invent endpoint URLs, API schemas, LLM provider versions, or deployment details during design handoff.
