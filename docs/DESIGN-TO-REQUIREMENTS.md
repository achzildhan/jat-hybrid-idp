## 3. Confirmed Design & Business Rule Resolutions (`DSN-TBD-01` – `DSN-TBD-06`)

All conflicts and ambiguities identified between the Stitch exports and `PRD.md` / `Business-Rules.md` have been resolved by stakeholder confirmation:

1. **`DSN-TBD-01` — Standardized Validation Status Labels (`Approved`, `Rejected`, `Waiting Confirmation`):**
   - **Resolution:** All UI status badges across both Student and Admin portals must display **`Approved`**, **`Rejected`**, and **`Waiting Confirmation`** (replacing `Accepted` and `Declined` from the raw Stitch Student HTML).
2. **`DSN-TBD-02` — Role Authorization for `Recalculate Progress`:**
   - **Resolution:** Both **`Admin` (Talent Support)** and **`Super Admin`** hold identical authority in JAT and can execute `Recalculate Progress`. The button label and permission logic allow `Admin` to trigger recalculation directly.
3. **`DSN-TBD-03` — Removal of Bulk Toolbar on `Waiting Confirmation` Queue:**
   - **Resolution:** The bulk action toolbar (`Konfirmasi Terpilih` / `Tolak Terpilih` and row selection checkboxes) shown in Stitch `9df4e619` is removed. Admin must review `Waiting Confirmation` items individually via the **HITL Evidence Inspector** (`b490bfff`) and provide a mandatory rejection reason whenever changing status to `Rejected` (`BR-24`).
4. **`DSN-TBD-04` — Out-of-Range `Date Applied` Submission & Auto-`Rejected` Status (`BR-14` & `BR-45`):**
   - **Resolution:** Students can still submit an application when `Date Applied` is outside the active Date Range, and the system automatically sets its validation status to **`Rejected`** (`BR-45`). Future dates remain disallowed (`BR-13`).
5. **`DSN-TBD-05` — Batch Deletion Confirmation Modal with Exact Batch-Name Input (`JAT-BL-16` & `BR-09`):**
   - **Resolution:** Admin Batch Management and Batch Detail include a **`Delete Batch`** action that opens a confirmation dialog requiring the Admin to input the **exact batch name** before confirming deletion.
6. **`DSN-TBD-06` — Full 7-Attribute IDP Comparison Checklist in HITL Inspector (`BR-39` & `BR-40`):**
   - **Resolution:** The HITL Evidence Inspector (`b490bfff`) checklist displays all **7 required attributes** from `BR-39` (`Date Applied`, `Role`, `Company`, `Location`, `Position`, `Job Level`, `Work System`), not a 4-item summary.
